# MIRAI ARCHITECTURE

---

# 1. Objetivo do Projeto

O Mirai é um aplicativo para leitura de mangás, manhwas e manhuas desenvolvido em Kotlin utilizando Jetpack Compose.

O objetivo do projeto não é apenas criar um leitor funcional, mas desenvolver uma aplicação moderna, organizada e fácil de manter por uma única pessoa ao longo dos anos.

O Mirai prioriza:

- qualidade máxima de leitura;
- alto desempenho;
- arquitetura organizada;
- facilidade de manutenção;
- código limpo;
- documentação completa.

Toda decisão técnica deverá seguir estes princípios.
